# Thumbnail & SEO Generation Skill

Generates the complete publishing package for completed video projects.

## Components of the Publishing Package

1. **Thumbnail System**:
   - 3 thumbnail prompt blueprints focusing on high-contrast focal points, clean silhouettes, and mobile readability.
   - For 16:9 videos: 1280×720 / 1920×1080 prompts with vivid color contrast.
   - For 9:16 Shorts: Note YouTube Shorts frame-selection rules and provide representative hero frame prompts.

2. **SEO Title Alternatives**:
   - 5 candidate titles (incorporating curiosity gaps, high-CPM keywords, and emotional payoffs).
   - Recommended title marked clearly.

3. **Description & Metadata**:
   - SEO-rich video description with synopsis, channel bio links, chapter markers (if >3 min), and relevant hashtags.
   - 10–15 comma-delimited YouTube Studio tags.
   - Suggested pinned comment for community engagement.

4. **Synthetic Media Disclosure**:
   - Generate required disclosure notes: "Contains realistic synthetic or altered video/audio" when applicable, complying with YouTube Community Guidelines.
