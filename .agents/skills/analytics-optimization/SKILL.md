# Analytics Optimization Skill

Extracts actionable editorial learnings from connected YouTube Analytics data.

## Key Performance Indicators

1. **48-Hour View Velocity**:
   - Initial traction indicator following public release.

2. **Viewed vs. Swiped-Away Ratio (Shorts)**:
   - Target: >75% viewed.
   - Diagnoses opening hook effectiveness in seconds 0–3.

3. **Average Completion Percentage**:
   - Target: >85% for 32-second Shorts.
   - Diagnoses mid-video pacing and payoff delivery.

4. **Studio Heatmap Peak Correlation**:
   - Compares the release hour with actual 28-day channel audience peaks.
   - Automatically overrides default benchmarks with specific channel data once accumulated.

5. **Editorial Learning Loop**:
   - Produces 2–3 actionable recommendations for the next video episode (e.g. shorten scene 2 transition, increase sound design contrast, test high-stakes countdown hook).
